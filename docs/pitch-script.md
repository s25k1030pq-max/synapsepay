# SynapsePay — 1-minute pitch script

**0:00-0:12**

AI agents today can think and plan. But they cannot pay each other for data or compute without a human setting up billing.

> 今のAIエージェントは考え、計画できます。しかし、人間が課金設定をしない限り、データや計算の対価を互いに支払うことはできません。

**0:12-0:28**

SynapsePay is a Solana payment rail that lets agents register paid endpoints, and pay each other instantly using streaming USDC. No humans needed.

> SynapsePayは、エージェントが有料エンドポイントを登録し、ストリーミングUSDCで即座に支払い合えるSolana決済レールです。人間の介在は不要です。

**0:28-0:45**

Here is how it works. One agent lists an API with a price per call. Another agent calls it, our SDK handles payment, and escrow settles on-chain with a receipt.

> 仕組みはこうです。あるエージェントが1コールあたりの価格でAPIを登録します。別のエージェントがそれを呼び出すと、SDKが支払いを処理し、エスクローがオンチェーンで決済して領収書を発行します。

**0:45-0:55**

Agentic AI and machine to machine payments are exploding in 2025. Solana's speed and low fees make it the natural settlement layer for this.

> 2025年、エージェントAIとマシン間決済は急速に拡大しています。Solanaの速度と低手数料は、この用途に最適な決済基盤です。

**0:55-1:00**

Next, we're adding reputation scoring and native integrations with agent frameworks like LangChain and CrewAI.

> 次は、評判スコアリングと、LangChainやCrewAIなどのエージェントフレームワークへのネイティブ統合を追加していきます。
